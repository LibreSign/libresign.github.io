# LibreSign legacy documentation redirects

This repository hosts the retired `https://libresign.github.io/` documentation domain. The canonical current documentation is at <https://docs.libresign.coop/>.

The old VuePress content is not rebuilt. The deployment workflow publishes only static redirect pages generated by `scripts/build-redirects.mjs`, with a `404.html` fallback for unknown or obsolete URLs. The fallback intentionally sends visitors to the developer manual rather than inventing a possibly invalid deep-link mapping.

All redirect pages include `noindex`, a canonical link, an immediate HTML refresh and a visible fallback link. GitHub Pages does not support arbitrary HTTP 301 rules for this hosted domain, so these are client-side navigation redirects. The fallback retains HTTP 404 status for unknown URLs even when a browser follows the refresh.

## Local validation

```sh
node --test scripts/test-redirects.mjs
node scripts/build-redirects.mjs dist
```
